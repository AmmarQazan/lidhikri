# مشاهد الفيديو الترويجي — لذكري

المدة المستهدفة: 45–55 ثانية. بدون تعليق صوتي طويل — النص العربي على الشاشة يكفي.

| ث | المشهد | ما يظهر | نص على الشاشة |
|---|--------|---------|----------------|
| 0–3 | افتتاح التطبيق | شاشة البداية الحقيقية: خلفية كريمية وشعار لذكري | — |
| 3–12 | تسبيح تلقائي | النافذة فوق الرئيسية + جملة كاملة + صوت | يذكّرك وأنت تستخدم هاتفك |
| 12–22 | تشغيل الأذكار | أذكار الصباح: بطاقات ثم قائمة + تشغيل صوتي | حصن المسلم بطريقتين |
| 22–32 | مواقيت وأذان وبعد الفرض | شاشة المواقيت، الأذان، وأذكار ما بعد الصلاة | أذان · مواقيت · أذكار بعد الفرض |
| 32–40 | المسبحة | المسبحة الإلكترونية والعدّ | مسبحة رقمية بلمسة |
| 40–48 | الويدجت | مسبحة تقليدية واحدة + ذكر اليوم | من الشاشة الرئيسية |
| 48–55 | ختام | نفس شعار الافتتاح + شعار قصير | يعمل دون إنترنت · بلا إعلانات |

**إلزامي:** مشهد المواقيت/الأذان/أذكار ما بعد الفرض لا يُحذف ولا يُستبدل بالمسبحة أو الويدجت.

## ملاحظات التصوير

- الافتتاح = فتح التطبيق على أندرويد (شاشة الشعار، ليست أيقونة وحدها).
- لغة الواجهة أثناء التسجيل: العربية.
- لا تظهر شاشة بحث جوجل ولا حوارات الأخطاء.
- الصوت: تسبيحة في المشهد 2، وذكر في المشهد 3.
- الدقة: 1080×2400، 8 fps للتسجيل الحالي.

## إعادة التسجيل

```bash
python scripts/record_promo.py
python scripts/assemble_promo_open_close.py
```
